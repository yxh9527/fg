# 流水字段变更清单（对齐用）

**索引：** `{Prefix}_gp_flowing_water`（当前 Prefix=`fg` → `fg_gp_flowing_water`）  
**写入方：** lottery（`SaveBill`）  
**时间：** `createTime` 为 **Unix 秒**

---

## 1. 字段（只列有变化的）

| JSON 字段 | 类型 | 含义 | 约定 |
| --- | --- | --- | --- |
| `bet` | float64 | 下注金额 | **负数**；无下注则为 `0` |
| `award` | float64 | **新增**。到账金额（返奖/回退等） | **>= 0**；无到账则为 `0` |

其余字段不变：`userId`、`agentId`、`gameId`、`symbol`、`currentScore`、`currency`、`currencySymbol`、`createTime`、`roundId`、`flowingWaterOn`、`desc`。

### 相对旧版

| 旧 | 新 |
| --- | --- |
| `bet` = 账变 delta（下注负、返奖正） | `bet` 只表示下注（负）；到账改走 `award` |
| 无 `award` | 必须按新字段读写（旧数据可能没有 `award`） |

---

## 2. 按 `desc` 写入约定

| desc | bet | award |
| --- | --- | --- |
| `下注` | `-本金` | `0` |
| `返奖` | `-本金`（本局有下注）或 `0` | `返奖金额`（>=0） |
| `结算` | `-本金`（有下注）或 `0` | `派奖金额`（>=0） |
| `回退` | `0` | `回退金额`（>0） |

> 没有单独的 `win` 字段；派奖/返奖金额都写在 **`award`**。

---

## 3. 示例

**下注 10：**

```json
{ "desc": "下注", "bet": -10, "award": 0, "currentScore": 90 }
```

**返奖 25（本金 10）：**

```json
{ "desc": "返奖", "bet": -10, "award": 25, "currentScore": 115 }
```

**结算派奖 25（本金 10）：**

```json
{ "desc": "结算", "bet": -10, "award": 25, "currentScore": 115 }
```

**回退 10：**

```json
{ "desc": "回退", "bet": 0, "award": 10, "currentScore": 100 }
```

---

## 4. 读侧兼容

```text
若文档存在 award 字段：
  下注额 = bet（负或 0）
  到账额 = award（>=0）
否则（旧数据）：
  仍把 bet 当作账变 delta 处理
```

---

## 5. 需要对齐的程序

| 程序 | 说明 |
| --- | --- |
| lottery | 已按上表写入 |
| client-api | `BillItem` 已含 `award`，原样返回 |
| 记录页 / 其它读流水 | 按 `bet` + `award` 解析；勿再把正数 `bet` 当返奖 |
| web-api / 报表 | 同上 |
